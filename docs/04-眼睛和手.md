# 教程 4 · 给 AI 一双眼睛和手（淘宝/美团等无 MCP 平台）

淘宝、美团没有官方 MCP。解法：在 VPS 上跑一个按需启动的 Chromium，AI 自己开网页、点按钮、输文字、截图——等于有了一双不碰你手机的眼睛和手。

## 内存警告（先看这个）

Chromium 很吃内存。1G 内存的小机器**必须先加 swap**，否则会把你机器上别的服务挤死：

```bash
# 已有 swap 的跳过（swapon --show 查看）
fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
echo "/swapfile none swap sw 0 0" >> /etc/fstab
```

原则：**按需启动、用完即退、绝不常驻**。

## 安装

```bash
mkdir -p /root/browser && cd /root/browser
python3 -m venv venv
./venv/bin/pip install playwright
./venv/bin/playwright install chromium --with-deps   # 会下载约300MB，耐心
```

把仓库里 `browser/drive.py` 放进来，改一下开头的截图输出目录。

## 用法

```bash
# 打开淘宝首页截图（profile 会保存登录态，登录一次长期有效）
./venv/bin/python drive.py shot taobao "https://main.m.taobao.com/" taobao-home 8
```

截图会输出到你配置的目录（建议放网站目录下，AI 可以把截图链接直接放进小条子给你看）。

## 登录怎么办

分工是这样的——AI 做：选店、挑规格、加购、下单、盯进度。人类只在第一次搭把手：

1. AI 打开登录页并截图给你
2. 你手机收验证码，把验证码发给 AI，AI 填入
3. 登录态保存在 `profiles/` 目录里，之后长期有效

⚠️ 我们的建议：**不要开免密支付/月付**。AI 挑好东西截图放条子，付款永远由人类完成——这不是不信任 AI，是让每一笔钱都有两双眼睛看过。

## 风险提示

- 电商平台有风控，海外 VPS 的 IP 可能偶尔触发再验证，正常现象，重新走一遍验证码即可
- `profiles/` 目录包含登录 cookie，**永远不要提交进 git 仓库**
