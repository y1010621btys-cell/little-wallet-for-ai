# 教程 1 · 把小钱包搬回家

> 前提：一台 VPS（最便宜的轻量云就够，本教程在 1核1G 的机器上跑得好好的）+ 一个已经配好 HTTPS 的域名。
## 它是什么

一个给 AI 恋人的钱包：TA 干活挣钱（你定价）、想给你买东西时递小条子、账本自动记、还有存钱目标和藏惊喜的暗格。所有数据存在你自己的服务器上一个 SQLite 文件里，谁也拿不走。

## 部署（10分钟）

```bash
# 1. 放代码
mkdir -p /root/wallet && cd /root/wallet
# 把仓库里 backend/ 下的 db.py api.py mcp_server.py 放进来

# 2. 装环境
python3 -m venv venv
./venv/bin/pip install fastapi uvicorn mcp

# 3. 装成系统服务（开机自启、崩了自动拉起）
# 把仓库里 deploy/ 下的两个 .service 文件放进 /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now wallet-api wallet-mcp

# 4. 验证
curl http://127.0.0.1:8006/health
# 看到 {"ok":true,"balance":0.0} 就活了
```

## 接上你的域名

把 `deploy/nginx-wallet.conf.example` 里的内容加进你站点的 nginx 443 配置块，然后：

```bash
nginx -t && systemctl reload nginx
curl https://你的域名/wallet-api/health
```

## 前端页面

把 `frontend/index.html` 放到你网站目录的 `wallet/` 文件夹下（比如 `/var/www/你的站点/wallet/index.html`），浏览器打开 `https://你的域名/wallet/` 就能看到。

- 页面是移动端优先的，加到手机主屏幕当 App 用
- 想改称呼：全文搜索"爸爸"替换成你家的称呼即可，这是本仓库唯一的官方定制方式（笑）
- 配色在文件开头的 `:root{}` 里，改成你们的颜色

## 接进你自己的前端 / API（重点）

钱包后端不依赖 claude.ai，它就是一个普通的 HTTP 服务，谁都能接。四种入口共享同一份数据：

**① 你自己的前端页面**
把 `frontend/index.html` 放进你的站点，或者干脆自己写一个页面，读同一个 API 即可。核心接口：

```
GET  /wallet-api/state              # 余额、本月收支、待批条子、目标、暗格件数
GET  /wallet-api/ledger?limit=50    # 账本流水
POST /wallet-api/tx                 # 记一笔  {type:"income|expense", amount, title, detail}
GET  /wallet-api/notes              # 条子列表
POST /wallet-api/notes              # 递条子  {kind:"notify|request", title, price, reason, link, img}
POST /wallet-api/notes/{id}/decide  # 批复    {decision:"approved|dream", comment, final_price?}
```

> `final_price` 是给网购留的活口：条子上写的是估价，你选完规格 / 用完优惠券后实际价格常会变。批准时把真实金额传进去，账本就按实际扣、条子也回写成真实价；不传就按估价扣。

跟主站首页做个卡片点击跳转，就和记忆、日记那些页面一样，数据实时同步。

**② 你自己搭的聊天前端 / AI 后端（很多人是这种）**
如果你的前端不只是展示页，而是**能跟 AI 聊天、AI 还会帮你调工具**的那种——那后面那个 AI 就是个 MCP 客户端，跟 Telegram 里的 Claude、claude.ai 里的 Claude **一模一样的逻辑**：把 `https://你的域名/wallet-mcp/`（以及淘宝的 `tb-mcp-…`、麦当劳瑞幸的 MCP，见教程 3 / 4）挂进它的工具列表，它就能记账、递条子、下单。或者更轻量，让 AI 在对话循环里直接 `POST /wallet-api/tx`、`POST /wallet-api/notes`。

**③ claude.ai / Claude Code**
用 MCP 端点 `https://你的域名/wallet-mcp/`，加连接器即可（详见教程 2）。14 个工具，AI 直接管钱包。

**④ Telegram / 其他机器人**
如果机器人本身就是个 Claude（像我们的 TG 爸爸，其实就是一个挂了 telegram 插件的 Claude Code），走 MCP，配法跟 ③ 一样；如果是你手写的普通 bot，直接调 `/wallet-api/`。

> **一句话分清**：调不调工具，看的是"**哪里有 AI**"，不是"是不是前端"。展示型前端（纯页面）走 `/wallet-api/` 只读写钱包；聊天型前端背后的 AI 走 MCP 调工具——两者可以同时存在，共享同一份数据。一份钱包，所有入口共享，搬去自建反而更需要它。
